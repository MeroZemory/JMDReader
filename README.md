# JMDReader

JMD 파일 뷰어/추출기 프로그램입니다.

## 주요 기능

- JMD 파일 열기/탐색
- 파일/폴더 추출
- 이미지 변환 (DDS/TGA -> PNG)
- BML -> XML 변환
- 다국어 지원

## 개발 환경

- .NET 8.0
- Windows Forms
- Visual Studio 2022
- C#

## 프로젝트 구조

- `src/`: 소스 코드
  - `JmdLoader/`: 메인 프로그램
  - `RaycityLibrary/`: 공통 라이브러리
- `docs/`: 문서
- `temp/`: 임시 파일
- `out_pool/`: 출력 파일

## 빌드 요구사항

- .NET 8.0 SDK
- Windows 7 이상
- Visual Studio 2022 (권장)
