# JMDReader UI 정보

## 메인 윈도우

### 메뉴바
- 파일
  - 열기: JMD 파일 열기
  - 종료: 프로그램 종료
- 추출
  - 모두 추출: 전체 파일 추출
  - 현재 폴더 추출: 선택 폴더 내 파일 추출
- 정보: 프로그램 정보
- 언어: 다국어 설정

### 탐색기 패널 (좌측)
- 트리뷰로 폴더 구조 표시
- 폴더 선택시 내용 표시

### 파일 목록 패널 (우측)
- 파일명/유형/크기 표시
- 파일 더블클릭시 미리보기
- 컨텍스트 메뉴
  - 파일 추출
  - 선택 항목 추출
  - PNG로 변환 (이미지)
  - XML로 변환 (BML)

### 상단 바
- 뒤로가기 버튼
- 현재 경로 표시

## 미리보기 창
- TGA/DDS 이미지 뷰어
- BML 뷰어
- 일반 파일은 기본 프로그램으로 열기

- 추출 옵션 설정
- 추출 진행 상태
