# 데이터 포맷

## 개요
JMDReader에서 사용하는 데이터 포맷 문서

## 문서 구조
- `jmd.md`: JMD 컨테이너 포맷
  - 파일 구조
  - 헤더 정보
  - 키 생성/관리
  - 데이터 처리

- `dds.md`: DirectDraw Surface 이미지
  - 파일 구조
  - 압축 포맷
  - 데이터 레이아웃

- `tga.md`: Truevision Graphics Adapter 이미지
  - 파일 구조
  - 이미지 타입
  - 데이터 구조

- `bml.md`: Binary XML 데이터
  - 파일 구조
  - 데이터 형식
  - XML 변환

- `compression.md`: 압축 알고리즘
  - zlib 압축
  - RLE 압축
  - 압축 처리

- `encryption.md`: 암호화 알고리즘
  - JMD 암호화
  - 키 관리
  - 보안 특성

## 관련 문서
- `flows/jmd_flow.md`: JMD 파일 처리 흐름
- `flows/details/`: 상세 처리 흐름
