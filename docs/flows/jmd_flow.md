# JMD 데이터 처리 흐름

## 파일 열기 과정

```mermaid
flowchart TD
    A[JMD 파일] --> B[식별자 검증]
    B --> C[헤더 읽기]
    C --> D[JMD 키 생성]
    D --> E[아카이브 정보 복호화]
    E --> F[데이터 정보 읽기]
    F --> G[디렉토리 구조 구성]
```

### 1. 식별자 검증
```
1. 0x00-0x3F: 레이어 식별자 읽기
2. 0x40-0x7F: 보조 텍스트 읽기
3. 레이어 버전 확인
```

### 2. 헤더 처리
```
1. 0x80-0xFF: 헤더 데이터 읽기
2. 체크코드 (0x53) 확인
3. 처리 모드 플래그 확인
4. Adler32 해시 검증
```

### 3. 키 생성
```
1. 파일명에서 JMD 키 생성
2. 디렉토리 키 생성
3. 데이터 정보 키 생성
4. 파일별 키 생성
```

## 데이터 처리 과정

```mermaid
flowchart TD
    A[데이터 블록] --> B{압축여부}
    B -->|Yes| C[zlib 해제]
    B -->|No| D{암호화여부}
    C --> D
    D -->|Yes| E[XOR 복호화]
    D -->|No| F[원본 데이터]
    E --> F
```

### 1. 데이터 블록 읽기
```
1. 데이터 정보에서 오프셋/크기 확인
2. 블록 속성 확인
3. 체크섬 검증
```

### 2. 압축 해제
```
1. zlib 스트림 생성
2. DEFLATE 데이터 처리
3. 압축 해제 크기 검증
```

### 3. 복호화
```
1. 키 준비 (파일/디렉토리)
2. XOR 복호화 수행
3. 부분 암호화시 분할 처리
```

## 디렉토리 구조 구성

```mermaid
flowchart TD
    A[루트 폴더] --> B[폴더 데이터 읽기]
    B --> C[하위 폴더 처리]
    B --> D[파일 목록 처리]
    C --> E[재귀적 구성]
    D --> F[파일 핸들러 생성]
```

### 1. 폴더 데이터
```
1. 폴더 수/파일 수 읽기
2. 폴더명/데이터 인덱스 읽기
3. 파일명/속성/크기 읽기
```

### 2. 파일 처리
```
1. 파일 핸들러 생성
2. 데이터 소스 연결
3. 파일 속성 설정
```

## 메모리 관리

```mermaid
flowchart TD
    A[JmdFileHandler] --> B[리소스 할당]
    B --> C[데이터 접근]
    C --> D[리소스 해제]
    D --> E[메모리 정리]
```

### 1. 리소스 관리
```
1. JmdFileHandler
- 파일 데이터 접근 제어
- 암호화 키 관리
- 아카이브 참조 관리

2. JmdDataSource
- 데이터 스트림 생성/관리
- 버퍼 메모리 관리
- 파일 핸들러 참조
```

### 2. 데이터 접근
```
1. getData() 호출시
- 핸들러 유효성 검증
- 아카이브에서 데이터 로드
- 메모리 버퍼 관리

2. 스트림 생성시
- 메모리스트림 생성
- 읽기전용 접근 제어
```

### 3. 리소스 해제
```
1. Dispose 패턴
- 관리 리소스 해제
- 비관리 리소스 정리
- 중복 해제 방지

2. 참조 정리
- 핸들러 release
- 스트림 close
- 버퍼 정리
```
